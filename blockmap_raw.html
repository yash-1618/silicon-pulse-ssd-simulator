Glossary of Symbols & Terms

P/E Cycle

Program/Erase cycle. Each block has a finite number of these before it wears out.

LBA

Logical Block Address. The address the OS sees, mapped to physical locations.

Garbage Collection

Internal process that cleans up "Stale" data blocks to make them "Empty" again.

Wear Leveling

Moving data around to ensure all blocks wear out at the same rate.

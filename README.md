💽 SILICON_PULSE_v1.0

SSD Wear-Leveling Simulator

📌 Overview

Interactive web app that visualizes SSD internals like wear-leveling, garbage collection, and WAF using a block-based simulation.

🚀 Features
1200-block SSD grid visualization
Wear distribution heatmap
WAF display
Scenario presets
Block inspector
Educational resources
🛠️ Tech Stack

React, Vite, Tailwind CSS, React Router

⚙️ Setup
git clone https://github.com/your-username/silicon-pulse-ssd-simulator.git
cd silicon-pulse-ssd-simulator
npm install
npm run dev
⚠️ Note

UI-based simulation (no real SSD logic yet)
